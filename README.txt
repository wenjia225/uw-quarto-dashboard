GitHub Pages files

1. Upload index.html and style.css to the root of your GitHub repository.
2. In Settings > Pages, choose Deploy from a branch.
3. Select Branch: main and Folder: /(root), then Save.
4. Wait a few minutes and refresh the Pages settings to find your public URL.
5. The map uses Leaflet and OpenStreetMap via online CDN; an internet connection is needed.

Before publishing, edit index.html if you want to change the name, introduction, or interests.
